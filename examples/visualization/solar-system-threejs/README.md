# 태양을 중심으로 움직이는 태양계 3D 그래픽

간단한 Three.js 예제를 통해 태양을 중심으로 여러 행성이 공전하는 3D 장면을 구성했습니다. 마우스로 시점을 회전하거나 줌을 조절하며 확인할 수 있습니다.

## 실행 방법

1. 의존성 설치가 필요하지 않습니다. 정적 파일을 띄울 수 있는 임의의 HTTP 서버만 있으면 됩니다.
2. 아래와 같이 예제 디렉터리로 이동한 뒤 로컬 서버를 실행하세요:

   ```bash
   cd examples/visualization/solar-system-threejs
   python -m http.server 8000
   ```

3. 브라우저에서 `http://localhost:8000`을 열어 태양계 애니메이션을 확인하세요.

## 구성 요소

- **Sun**: 발광 재질로 표현된 중앙의 태양과 주변을 밝히는 `PointLight`
- **Planets**: 간단한 반지름, 거리, 속도 값을 가진 행성들이 시계 방향으로 공전
- **Rings & Stars**: 토성의 고리와 장면 전체에 분포된 별 입자 배경
- **OrbitControls**: 마우스 드래그와 스크롤로 시점 이동 및 확대/축소 지원
